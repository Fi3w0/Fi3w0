## 🛠️ Projects

**[TideWM](https://github.com/Fi3w0/TideWM)**: a water-themed Wayland compositor in Rust on Smithay. Tiling (BSP/master-stack), multi-monitor, XWayland, workspaces, and IPC.

**[Flux](https://github.com/Fi3w0/Flux)**: native macOS media workbench. Convert, download, edit, and compose media in one app, built on SwiftUI + AppKit over FFmpeg, yt-dlp, and Apple Vision. Fully local, no accounts, no cloud, no telemetry.

**[Moonlit Shell](https://github.com/Fi3w0/Moonlit-shell)**: handcrafted Arch + Hyprland desktop with a custom Quickshell (QML/Qt6) interface. Twelve native panels, one Catppuccin Mocha theme throughout, no monitoring daemon between the UI and `/proc`.

**[FIW Bosses](https://github.com/Fi3w0/Fiw-Bosses)**: JSON-driven, multi-loader (Fabric/NeoForge/Forge) boss framework. 50+ abilities, HP-phases, custom minions, dialogue, loot, hot reload. On Modrinth.

**[FIW Tools](https://github.com/Fi3w0/Fiw-Tools)**: sibling mod to FIW Bosses. Server-side, JSON-only custom items: weapons, armor, curses, and an imbuing engine. Vanilla clients connect fine.

More at [fiwlabs.dev](https://fiwlabs.dev) and [github.com/Fi3w0?tab=repositories](https://github.com/Fi3w0?tab=repositories).
